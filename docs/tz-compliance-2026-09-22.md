# Перевірка ТЗ — 22.09.2026

Цей файл фіксує реалізовані робочі контури та перевірки для наданого ТЗ.

| Вимога | Реалізація та перевірка |
| --- | --- |
| CRM клієнтів | Автостворення з Telegram/web, дедуплікація за міжнародним телефоном, нотатки, історія бронювань і LTV, пошук, XLSX/CSV імпорт та XLSX експорт. |
| Диспетчеризація | Тижневий планувальник по автомобілях, drag-and-drop на 15-хвилинну сітку, атомарне серійне планування; PostgreSQL забороняє перетини водія й автомобіля. |
| Статуси | Власні статуси маршрутів, рейсів, авто, водіїв, заявок, бронювань і платежів з системною семантикою для бізнес-правил. |
| Telegram | `/start`, вибір маршруту/дати/рейсу, пасажири, додаткові поля, бронювання, індивідуальна заявка, мої поїздки, скасування та надійна черга повідомлень. |
| Публічне бронювання | Окремі поля імені/прізвища латиницею, дата народження, телефонний компонент, декілька пасажирів, явний метод оплати, ID бронювання та захист від повторів/овербукінгу. |
| IBAN оплата | Direct-to-IBAN checkout, NBU QR, точна сума, унікальне призначення, 30-хвилинний hold, захищений polling статусу, ручне та автоматичне підтвердження. |
| Monobank звірка | Персональний API, гривневий рахунок за точним IBAN, statement не частіше разу на 65 секунд; збіг вимагає точну суму і `VIVAT-…`, повтор транзакції відсікається БД. |
| Тарифи | Фіксована ціна або відстань × тариф класу авто; валюта та модель «за пасажира / за бронювання» знімкуються в рейс і бронювання. |
| Водійська зарплата | Сума задається на маршруті, знімкується в рейс і один раз створює витрату `driver_pay` після завершення рейсу. |
| Фінанси | Виручка, готівка водія, здача каси, паливо, зарплата, амортизація, маркетинг, інші витрати і чистий результат. EUR/USD/PLN/UAH конвертуються за курсами власника; відсутній курс показується явно. |
| GPS | Водійська PWA, передача точок, офлайн-черга, дедуплікація, прив’язка до призначеного рейсу, карта автопарку та контроль свіжості. |
| Ролі | Власник, адміністратор, диспетчер, водій і розробник; розробник проходить усі role-gates, секрети й реквізити доступні лише власнику/розробнику. |
| Час | Запис у UTC, ввід/відображення в часовому поясі компанії. |

## Перевірки випуску

- `go test ./...`
- `npm test`
- `npm run typecheck`
- `npm run lint -- --quiet`
- `npm run build`
- міграції застосовуються послідовно до актуальної schema version;
- після push перевіряються точний SHA у Coolify, health API, версія схеми, публічний checkout і запуск Telegram bot.
